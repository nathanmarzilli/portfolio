Notifications automatiques (RDV)

Dès qu'une demande arrive sur le site, la base de données prévient toute seule le service que vous aurez branché ci-dessous — vous recevez l'e-mail et l'événement d'agenda même si le visiteur ferme son onglet juste après avoir validé. Collez l'adresse de ce service dans les deux champs ci-dessous (la même adresse convient aux deux, le service reconnaît de lui-même une demande de RDV d'un brief projet).

Solution recommandée — gratuite, et directe : Google Agenda + Gmail

Pas besoin de Zapier ni d'abonnement : un petit script Google (« Apps Script »), posé une fois sur votre propre compte Google, crée l'événement dans votre agenda et envoie l'e-mail (à vous, et un accusé de réception au client) au moment même de la réservation.

  1. Ouvrez script.google.com (avec votre compte Google habituel) → Nouveau projet.
  2. Copiez le contenu du fichier integrations/notifications-agenda-gmail.gs (livré avec le site) dans l'éditeur, à la place du code par défaut.
  3. Tout en haut du script, remplacez CHANGE_ME par un mot de passe de votre choix (gardez-le, il vous servira à la dernière étape).
  4. Déployer → Nouveau déploiement → type Application web → « Exécuter en tant que » : Moi · « Qui a accès » : Tout le monde, puis Déployer (autorisez l'accès à votre agenda et à Gmail quand Google le demande).
  5. Copiez l'adresse fournie (elle ressemble à https://script.google.com/macros/s/…/exec), ajoutez ?key= suivi du mot de passe choisi, et collez le tout dans les deux champs ci-dessous.
Vous préférez Zapier ? (nécessite un forfait payant)

Le déclencheur générique « Webhooks by Zapier → Catch Hook » n'est disponible que sur les forfaits payants de Zapier. Si vous passez sur un tel forfait un jour : ouvrez le Zap → son déclencheur → Webhooks by Zapier → Catch Hook → copiez l'adresse https://hooks.zapier.com/hooks/catch/… et collez-la ci-dessous à la place de l'adresse Google. Les champs envoyés sont les mêmes dans les deux cas (first_name, last_name, email, rdv_label, pack_label, estimated_total…).

Facturation Stripe

L'envoi des factures passe par une fonction serveur, pour que votre clé secrète Stripe ne se retrouve jamais dans le code du site. Ajoutez-la une seule fois dans Supabase → Edge Functions → Secrets, sous le nom STRIPE_SECRET_KEY. Le bouton « Envoyer la facture » devient alors opérationnel, sans rien changer au code.
